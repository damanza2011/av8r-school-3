3. Arquitectura y Especificaciones de Despliegue

Infraestructura Frontend

HTML5 Semántico, CSS Tokens (#070B11, #FF1E27, #F8FAFC) y ES6 Modular nativo sin dependencias pesadas para carga ultrarrápida (< 0.5s).

Seguridad y Entrega

Alojado en Vercel Edge Network con HTTPS forzado, cabeceras de seguridad (X-Frame-Options, nosniff) y enrutamiento limpio (cleanUrls: true).

Asistente Profesor N3570R

Módulo de orientación bilingüe con respuestas instantáneas sobre requisitos FAA, Skool, YouTube y enlace directo al WhatsApp (+1 561 715-8036).

Preparación para Dominio y Shopify

Listo para conectar www.av8rschool.com vía DNS en Vercel y redirigir /store hacia la tienda Shopify cuando Nestor dé el acceso.
